# 持仓管理

## 文件格式

`portfolio.yaml` 采用**交易流水**格式，每笔买卖独立记录，历史永不丢失：

```yaml
transactions:
  - date: "20240315"
    code: "600489.SH"
    action: buy
    shares: 100
    price: 22.501
    comment: "黄金板块启动"

  - date: "20260725"
    code: "600489.SH"
    action: sell
    shares: 100
    price: 300.00
    comment: "止盈卖出"
```

## 字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| `date` | 交易日期 YYYYMMDD | `"20240315"` |
| `code` | 股票代码 | `"600489.SH"` |
| `action` | `buy` 买入 / `sell` 卖出 | `buy` |
| `shares` | 股数 | `100` |
| `price` | 成交价 | `22.501` |
| `comment` | 备注（选填） | `"黄金板块启动"` |

## 自动计算

系统从交易流水中自动推算：

- **当前持仓**：买入总量 - 卖出总量，FIFO 计算平均成本
- **浮动盈亏**：当前持仓 × (最新收盘价 - 平均成本)
- **已平仓交易**：每笔卖出按 FIFO 匹配买入，计算单笔收益率和盈亏
- **历史统计**：胜率、累计已实现盈亏

## 日常操作

### 买入时

在 `transactions` 列表末尾追加一条 `buy` 记录。

### 卖出时

在 `transactions` 列表末尾追加一条 `sell` 记录。**不必删除原有的 buy 记录**——系统自动通过 FIFO 匹配计算盈亏。

### 查看持仓状态

```bash
./go-quant signal -n 5
```

输出示例：

```
========== 持仓概览 ==========
  600489.SH  中金黄金  100股 | 22.50 | 294.30 | +1207.9% | +27180 ███████████████
  总成本: 2250 | 总市值: 29430 | 浮动盈亏: +1207.93%

========== 历史交易 ==========
  20240315 → 20260725  600489.SH  中金黄金  100股 | 22.50→300.00 | +1233.3% | +27750
  已平仓 1 笔 | 胜率 100% | 累计盈亏 +27750
```

## 自动存档

每次运行 `signal` 后自动保存到 `data/raw/reports/`：

| 文件 | 用途 |
|------|------|
| `portfolio_summary.json` | 完整 JSON 数据 |
| `current_holdings.csv` | 当前持仓表，Excel 可打开 |
| `closed_trades.csv` | 已平仓交易表，用于回测和统计 |

**重要**：每次买卖后都要及时更新 `portfolio.yaml`，否则持仓和盈亏统计不会包含新操作。
