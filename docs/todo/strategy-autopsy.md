# 量化指标尸检报告

本文记录 2026-08-01 对原 24 个注册策略的逐项尸检和第一次去重结果。目的不是从同一段历史数据中挑出看起来最赚钱的参数，而是先删除没有独立假设、名称与实现不一致、或已经被更完整规则覆盖的指标，给后续事件驱动研究留下一个更小、更可解释的技术工具箱。

## 结论

- 注册策略从 24 个减到 13 个：10 个日常技术策略、3 个慢频基本面策略。
- 11 个策略退役并删除实现。旧 `config.yaml` 里的退役名称会在默认日终和默认回测中自动过滤；命令行显式指定退役名称时仍会按未知策略处理，不会悄悄换成另一个策略。
- 本轮没有任何技术策略被认定为已经证明有效的 Alpha。保留只代表交易假设相对独立、实现与名称基本一致，值得作为事件信号的择时/确认工具继续验证。
- 策略列表变化会使旧的历史验证证据指纹失效。需要使用新列表重新运行 `validate build`，不能沿用旧 `evidence.json` 的正式资格结论。

## 判断标准

删除不是按一次回测盈亏排序，而是依次检查：

1. **信息是否独立**：是否只是同一价格序列、同一窗口和同一阈值的轻微变形。
2. **名称是否诚实**：名称表达的交易假设是否真的在代码中实现。
3. **是否存在更完整的替代项**：若一个策略的触发前提被另一个策略完全包含，优先保留风险约束更完整者。
4. **规则是否产生持续追涨或重复信号**：连续多日重复触发同一状态而不是状态切换，会制造换手和样本相关性。
5. **统一诊断是否支持该判断**：收益、回撤和交易次数只作旁证，不能单独决定删除。

`market_neutral_momentum` 没有放进上表的逐股票横截面统计。它是 `relative_strength` 的 beta 残差变体，必须看共享资金组合消融。此前 2021-01-01～2026-07-31 正式消融中，加入它只把净收益从 -61.11% 改善到 -60.57%，实验组仍显著亏损且不满足准入门禁，因此本次一并退役，而不是继续保留一个没有增量证据的实验分支。

三个慢频策略 `dividend_deviation`、`quality_value`、`earnings_growth` 没有混入日常技术指标诊断。它们保留在月度/季度基本面流程中，后续应使用公告时点和当时可见财务数据单独验证。

## 重叠关系

| 原策略 | 重叠或替代关系 | 处理 |
|---|---|---|
| `donchian` | 与 `atr_breakout` 共用前 20 日高点突破；后者增加 ATR、量能和 MA60 过滤 | 删除前者 |
| `roc`、`etf_rotation`、`market_neutral_momentum` | 都从价格动量产生方向；保留真正横截面的 `relative_strength` | 删除三个变体 |
| `williams_r` | 与 KDJ 的 RSV 都来自窗口最高、最低和收盘位置 | 保留带平滑和交叉确认的 `kdj` |
| `mfi` | RSI 的成交量加权变体；量能信息另由 `volume_breakout` 提供 | 删除有已知计算缺陷的变体 |
| `bull_flag`、`ma_sticky` | 都是缩量/低波动后的价格确认，但前者没有旗杆，后者退出不完整 | 保留假设完整的 `trend_pullback` 与 `atr_breakout` |
| `value_ma60` | MA60/布林技术退出叠加价值过滤，与技术策略和三个基本面策略重复 | 拆除混合职责 |
| `bottom_reversal` | 跌幅、MA、量能和换手的组合，没有独立事件或基本面来源 | 删除拼接策略 |
| `limit_up` | 不是信息重复，而是直接编码事后追涨 | 因假设不再接受而删除 |

`ma_crossover` 与 `macd` 都属于趋势组，但暂不互相替代：前者描述短长均线水平关系，后者描述 EMA 差值的加速度变化。`rsi`、`kdj`、`bollinger` 也都属于反转组，但分别度量收益平衡、区间位置和波动率偏离。它们仍会受到同组限权，后续若事件回测证明没有增量，可以继续删减。

## 当前保留清单

| 用途 | 策略 |
|---|---|
| 超卖/偏离确认 | `rsi`、`kdj`、`bollinger` |
| 趋势状态与退出参考 | `sar`、`ma_crossover`、`macd` |
| 量价/形态确认 | `volume_breakout`、`atr_breakout`、`trend_pullback` |
| 横截面研究候选 | `relative_strength` |
| 慢频基本面研究 | `dividend_deviation`、`quality_value`、`earnings_growth` |

这些技术指标不再天然拥有主要选股权。下一阶段的事件/财报回测应先建立不用技术指标的规则基线，再逐个加入上述确认项做消融；只有改善样本外净收益、回撤或容量的指标才继续保留。

## 运行影响

默认日终和默认回测现在只使用 10 个日常策略。`config.yaml` 的 `signal.default_strategies` 已按本表更新为 10 个策略（含 `rsi`、`sar`、`ma_crossover`、`trend_pullback`）。

完成策略列表变更后重新构建证据：

```bash
./go-quant validate build
./go-quant backtest --ensemble
```

上面的 -52.08% 是删减后的冻结研究基线，不是可部署结果。重建 `evidence.json` 只是保证证据与新代码一致，不会把负期望组合自动变成合格策略；正式推荐仍会在证据不足或不合格时失效关闭。

2026-08-12 更新：正式资格门槛已从“绝对正期望收益”改为“跑赢等权市场代理基准”（`validation.min_alpha_pct`，默认 0.5%），证据回放不再套用仓位策略（覆盖全部市况与周期，样本从 6k 扩展到 26 万），并新增“轻仓试错”通道（非空头市况且无合格候选时，单票仓位≤3% 的候选进入前向测试验证）。同日又追加 `validation.max_drawdown_pct`（默认 -45%）门槛：原 alpha 合格的 19 个桶中，中线突破组合普遍胜率 32-43%、回撤 -46%~-67%，全部被拦下，正式买入现在只来自短线反转组合（bollinger+rsi、rsi+sar、bollinger+sar+volume_breakout、kdj+rsi 等，胜率 41-60%、回撤 -13~-39%）。`relative_strength` 在所有市况和组合中持续拖累 alpha（未进入任何合格桶），已从 `signal.default_strategies` 移除（代码保留为研究项）。同日修复：KDJ 一字板/停牌日不再把 K/D 状态清零（原实现制造虚假低位金叉）；`relative_strength` 历史日期无横截面预计算时返回 Hold，禁止静默降级为单股动量；组合预算按“同策略签名”设集中度上限（同日同组合视为一个赌注，合计不超过单票上限）。
