# 策略审阅结论与修正计划

审阅日期：2026-07-30

## 结论

项目已经正确区分了策略计算使用的前复权价格和成交使用的真实价格，也实现了 T+1 成交、涨跌停不可成交、基本面公告日查询与横截面策略的历史排名。这些是继续演进的可靠基础。

但在以下问题修正前，`backtest`、`forward validate` 与 `signal` 输出都不能被当作可直接实盘执行或用于证明组合正期望的结果：

1. 市场情绪使用的股票集合与信号使用的集合不同；过期和 ST 股票仍会影响市场宽度、涨跌停统计及仓位决策。
2. `min_market_cap` 在信号加载阶段只检查基本面是否存在，未按配置阈值过滤市值；日常补数也没有复用历史抓取的市值过滤口径。
3. 实时行情只校验预截断候选，仓位策略却评估全量候选；被过滤的前排候选不会由下位合格候选补位。
4. 空仓记录会写入 `CASH`，但前向验证找不到它对应的行情并跳过，无法验证空仓是否避险。
5. `etf_rotation` 运行于 A 股股票池，并非 ETF 轮动；`dividend_deviation` 在缺失股息数据时仍可给出买入；Williams %R 的评分方向与反转策略不一致。
6. 回测目前是单标的满仓回测的样本平均，不是生产选股和仓位规则的组合回测；同时存在当前成分股带来的幸存者偏差。它可用于策略单元回归，不能单独作为组合收益结论。
7. 策略注册、元数据、默认配置和文档存在多处重复维护，已经发生 21/23 个策略不一致。

## 本次实施范围与验收标准

本次修正优先建立可复用的深模块，使同一份可交易股票集合、候选过滤规则和数据口径被市场分析、信号输出、前向记录与测试共同使用。

### 1. 数据集与市场状态

- 数据集提供经过最新交易日、ST 与市值筛选后的统一股票集合。
- 市场状态只分析这一集合的完整历史，不再读取未筛选的 `Bars`。
- 市值过滤以分析日的 `daily_basic.total_mv` 为准；缺少当日或此前基本面数据的股票会被排除。
- 测试覆盖过期股票、ST 股票、小市值股票均不会进入市场统计或候选集。

### 2. 候选与实时风控流水线

- 将候选筛选封装为一个流水线：原始排名 → 扩展候选池 → 实时校验 → 风控过滤 → 每周期补位 → 仓位决策。
- 仓位决策只能看到实际可交易候选；输出 Top-N 被风险标签淘汰后应由下一名合格候选补位。
- 测试覆盖“榜首高开被过滤、次名补位”和“未校验候选不能影响仓位决策”。

### 3. 前向验证

- `CASH` 记录保存同期基准指数或市场代理的目标日及各周期收益，不再被静默跳过。
- 前向结果继续使用真实成交价，并明确它是信号观察结果，不替代组合回测。
- 测试覆盖空仓记录的写入与回填。

### 4. 策略语义

- 将原 `etf_rotation` 明确为股票动量均线策略，避免把非 ETF 股票信号当成资产轮动。
- `dividend_deviation` 必须取得可用且合理的股息率才可买入。
- 修正 Williams %R 评分方向，并为策略注册的元数据和默认配置建立一致性测试。

### 5. 回测与文档

- 本次修正 Sharpe/Calmar 的计算口径，并在输出中明确单标的样本汇总的限制。
- 组合级回测、历史可交易池与完整的印花税/最小佣金模型需要额外的数据与产品决策，保留为下一阶段；不会把单标的平均收益包装为组合回测。
- README、Agent 指南、示例配置均以 23 个策略和当前前向测试周期为准。

## 不变量

- 技术指标继续使用前复权 OHLC；回测成交、前向入场和盘中风险判断继续使用真实 OHLC。
- 财务指标继续按公告日而非报告期结束日取得，防止未来函数。
- 不将新浪盘中数据写入历史行情，也不让它进入历史回测。
